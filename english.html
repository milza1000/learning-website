ไวยากรณ์ภาษาอังกฤษระดับสูง

สรุปเนื้อหาไวยากรณ์ขั้นสูง • พร้อมแบบฝึกหัดและเฉลยละเอียด

1. The passive with preparatory there

วัตถุประสงค์ : ใช้รายงานข้อมูล ข่าวสาร หรือสิ่งที่เชื่อกันโดยทั่วไป โดยไม่ต้องระบุแหล่งที่มาหรือผู้ให้ข้อมูลแน่ชัด

There + (is/are/was/were) + V.3 + to be + noun phrase
  • กริยาที่นิยมใช้ : believe, consider, estimate, expect, feel, know, presume, report, say, suppose, think, understand
  • ตัวอย่างประโยค : There is believed to be a tunnel that leads from the house to the sea.

การผันกริยาตามพจน์ : กริยาช่วยต้องผันให้สอดคล้องกับจำนวนของ Noun phrase ที่ตามมาข้างหลัง

  • ประธานเอกพจน์ : There is said to be a cask of gold...
  • ประธานพหูพจน์ : There are thought to be thousands of undiscovered species...
ข้อควรระวังสำคัญ :
• โครงสร้าง Preparatory there ไม่สามารถ ตามด้วย that-clause ได้
• หากต้องการใช้ that-clause ต้องเปลี่ยนไปใช้ Preparatory it แทน เช่น It is thought that there are thousands... (ห้ามใช้ There is thought that...)
• มักไม่นิยมใช้รูป Present Perfect Passive (has/have been reported) ในโครงสร้างนี้ แต่จะใช้ Present Passive หรือย้ายคำนามขึ้นมาเป็นประธานแทน

2. Gerund forms (Perfect, Passive, Negative)

คำนิยาม : Gerund คือกริยาเติม -ing ที่ทำหน้าที่เป็นคำนามในประโยค (ทำหน้าที่เป็นประธานหรือกรรม)

  • รูปปฏิเสธ (Negative Gerund) : วางคำว่า not ไว้หน้า Gerund และต้องใช้รูปเต็มเสมอ ห้ามใช้รูปย่อ เช่น not understanding, not having
  • Perfect Gerund (having + V.3) : ใช้แสดงเหตุการณ์ที่เกิดขึ้นและเสร็จสิ้นสมบูรณ์ก่อนอีกเหตุการณ์หนึ่ง
    ตัวอย่าง : Having written the story, she wanted to get it published.
  • Passive Gerund (being + V.3) : ใช้เมื่อประธานเป็นผู้ถูกกระทำ
    ตัวอย่าง : ...the only thing worse than being talked about was not being talked about.
Prepositions / Verbs (love, suggest, recall, remember, start, stop) + Gerund

3. Preparatory it as subject

วัตถุประสงค์ : เมื่อประธานจริงของประโยคเป็น Infinitive (to + V.inf) หรือประโยคย่อย (Clause) ภาษาอังกฤษจะไม่นิยมนำมาขึ้นต้นประโยค แต่จะใช้ It เป็นประธานเกริ่นนำแทน

It + form of be + Adjective (หรือ Adj + Noun) + to + V.infinitive
  • ตัวอย่าง : It is very healthy to eat oily fish. (แทนที่จะพูดว่า To eat oily fish is very healthy.)
  • กริยาเชื่อมอื่น : appear, become, feel, get, look, seem, sound, stay

โครงสร้างร่วมกับ Clause : It + form of be + Adjective + clause (ขึ้นต้นด้วย that, what, who, when)

  • ตัวอย่าง : It's unlikely that you've met Tom before.
ข้อควรระวัง : ห้ามใช้ Preparatory it เมื่อประธานจริงเป็นวลีคำนาม (Noun phrase) อยู่แล้ว

4. Preparatory it as object

วัตถุประสงค์ : เมื่อกรรมของประโยคมีความยาว เช่น เป็น Infinitive หรือ Clause จะใช้ it มาทำหน้าที่เป็นกรรมเกริ่นนำ

Subject + Verb + it + Adjective (หรือ Adj + Noun) + [to + V.infinitive / clause]
  • ตัวอย่าง 1 : I found it difficult to work with him.
  • ตัวอย่าง 2 : The instructions will make it clear where you're supposed to go.
ข้อควรระวังในการใช้งาน :
• ห้ามใส่คำปฏิเสธไว้หน้า Adjective ให้ทำเป็นรูปปฏิเสธที่กริยาหลักแทน เช่น He didn't think it strange...
• ห้ามใส่ it เป็นกรรมหากกริยาหลักไม่ได้ตามด้วย Adjective หรือ Adjective + Noun
